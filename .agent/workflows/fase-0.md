# fase-0: Persiapan

1. Baca AGENTS.md dan docs/PRD.md sebagai konteks. Jika belum ada repo git, jalankan git init.
2. Baca docs/phases/fase-0.md dan kerjakan semua tugas serta batasannya. Jangan mengerjakan fase lain.
3. Jalankan npm run lint, npm test, dan npm run build.
4. Jika ada yang gagal: perbaiki dan ulangi, maksimal 3 kali. Jika masih gagal, BERHENTI dan laporkan masalahnya beserta dugaan penyebab. Jangan commit kode yang gagal build.
5. Cocokkan hasil dengan bagian "Selesai jika" di docs/phases/fase-0.md. Untuk tiap kriteria tulis terpenuhi atau tidak. Beberapa kriteria hanya bisa dinilai manual (tampilan, rasa animasi, uji di HP). Untuk itu tulis "perlu uji manual" dan jelaskan cara mengujinya.
6. Jika semua otomatis lolos, jalankan git add -A lalu git commit -m "chore: fase 0 persiapan project".
7. Tulis ringkasan singkat: file yang dibuat atau diubah, cara mengujinya, dan hal yang perlu saya cek manual.
