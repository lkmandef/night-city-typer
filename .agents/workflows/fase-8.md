# fase-8: Performa dan Aksesibilitas

1. Jalankan git log --oneline dan pastikan fase 7 sudah di-commit. Jika belum, BERHENTI dan beri tahu saya.
2. Baca AGENTS.md dan docs/PRD.md sebagai konteks.
3. Baca docs/phases/fase-8.md dan kerjakan semua tugas serta batasannya. Jangan mengerjakan fase lain.
4. Jalankan npm run lint, npm test, dan npm run build.
5. Jika ada yang gagal: perbaiki dan ulangi, maksimal 3 kali. Jika masih gagal, BERHENTI dan laporkan masalahnya beserta dugaan penyebab. Jangan commit kode yang gagal build.
6. Cocokkan hasil dengan bagian "Selesai jika" di docs/phases/fase-8.md. Untuk tiap kriteria tulis terpenuhi atau tidak. Beberapa kriteria hanya bisa dinilai manual (tampilan, rasa animasi, uji di HP). Untuk itu tulis "perlu uji manual" dan jelaskan cara mengujinya.
7. Jika semua otomatis lolos, jalankan git add -A lalu git commit -m "perf: fase 8 performa dan aksesibilitas".
8. Tulis ringkasan singkat: file yang dibuat atau diubah, cara mengujinya, dan hal yang perlu saya cek manual.
