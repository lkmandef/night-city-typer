# Night City Typer

Seni generatif interaktif: ketik di keyboard dan saksikan panorama kota malam tumbuh gedung demi gedung.

## Menjalankan Project

### 1. Jalankan development server
```bash
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) di browser.

### 2. Jalankan test suite
```bash
npm test
```

### 3. Build untuk produksi
```bash
npm run build
```

### 4. Linting
```bash
npm run lint
```
