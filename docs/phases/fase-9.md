# Fase 9: Metadata dan Rilis

Fase 9: metadata, SEO, dan kesiapan rilis.

Tugas:
1. Di app/layout.tsx isi metadata lengkap: title "Night City Typer", description "Ketik, dan kota malam tumbuh dari hurufmu. Spasi membuat jalan, backspace memadamkan lampu.", openGraph (type website, siteName, title, description, images), twitter (card summary_large_image), themeColor #050816, dan metadataBase memakai URL placeholder yang mudah diganti.
2. Tambahkan referensi gambar /og.png (1200x630). Buat file placeholder dan beri tahu saya langkah mengganti dengan tangkapan layar asli.
3. Tambahkan favicon sederhana bergaya gedung malam (SVG di app/icon.svg).
4. Tambahkan <noscript> berisi penjelasan singkat project.
5. Opsional: pasang @vercel/analytics dan tambahkan <Analytics /> di layout.
6. Perbarui README: deskripsi, cara menjalankan, struktur folder, kontrol (huruf, spasi, backspace, enter), catatan inspirasi (terinspirasi dari Type Garden, seluruh kode dan visual dibuat sendiri), dan placeholder untuk tangkapan layar.
7. Pastikan npm run build dan npm test lolos tanpa warning penting.

Batasan: jangan mengubah logika inti.

Selesai jika: build sukses, metadata tampil benar di tab dan saat dibagikan, README siap.
