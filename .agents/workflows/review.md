# review

1. Jalankan git log --oneline dan lihat diff commit terakhir.
2. Cari bug, memory leak, pelanggaran aturan di AGENTS.md (misalnya logika di lib/city mengimpor React atau canvas), dan bagian yang sulit diuji.
3. Beri daftar temuan berurutan dari yang paling penting.
4. Jangan mengubah kode. Tunggu saya memilih temuan mana yang diperbaiki.
