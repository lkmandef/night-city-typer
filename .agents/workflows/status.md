# status

1. Jalankan git log --oneline dan git status.
2. Tentukan fase terakhir yang sudah di-commit (cari "fase N" di pesan commit).
3. Beri tahu: fase yang sudah selesai, fase berikutnya, dan checkpoint manual terdekat yang perlu saya lakukan.
4. Jalankan npm run build dan npm test, lalu laporkan hasilnya singkat.
5. Jangan mengubah file apa pun.
